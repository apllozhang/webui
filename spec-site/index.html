Character

设计气质

清爽感的四个来源（TSSKB 实测归纳）

大面积中性底

画布 #F7F7F5 + 白色表面，品牌紫只出现在关键动作与强调位（10–15%）。

标题用深紫

标题 #4F3478 而非纯黑，正文近黑 #1A1A1A —— 品牌感来自文字色而非色块。

两档浅色分隔

主边框 #D9D9D6 与次级柔和线 #E9E8E4（虚线），避免满屏等重边框。

紫灰阴影 + 轻浮起

阴影带紫灰色调（非纯黑），浮起 -2px 级，克制而可感知。

Architecture

产品家族与交互模式

先选产品家族，再选交互模式；工程档由两者共同决定。同一系统可横跨多行，相同组件必须同样式。

内容网站型

知识库、培训、产品信息。阅读体验优先。

交互模式: 阅读门户 · 检索目录 · 长文详情 — 工程档 TSSKB → Static

工具应用型

数据管理、采集、报价、批处理。操作效率优先。

交互模式: 数据工作台 · 轻量单任务 · 多步向导 — 工程档 React / Alpine（dan-cpl · nvci-lite）

注：React / Alpine / Static 是工程档（技术选型），不是产品类型。

Motion

动效与微交互

四档时长令牌 + 三个统一动效语言：按钮浮起、卡片浮起、页面入场（一次性）。

160ms240ms560ms≤300ms
按钮浮起：试试悬停上方按钮
card--interactive 卡片浮起：试试悬停本卡
↓ 12px 入场动画：点击重放
浮动只给可交互元素；同屏同时浮起不超过悬停的那个；入场动画仅首屏一次；列表不逐项延迟；必须支持 prefers-reduced-motion。

Acceptance

无障碍与验收清单

正式项目至少满足 WCAG 2.2 AA 核心要求；自动化检查不能替代人工键盘与读屏抽查。

错误信息公式

发生了什么 + 对用户造成什么影响 + 用户现在能做什么。诊断编号放次要位置并支持复制。
