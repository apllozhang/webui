## 3. 关于 1100KiB FONT-BUDGET 的专业意见

**接受用于 RC 签收。** 该值不是随意放宽：它覆盖两个已知浏览器环境的真实分片选择差异，并为较重的 CI Chrome 留出有限余量。门禁文案同时保留正式优化目标，因而没有把“性能达标”与“防异常回归”混为一谈。

建议正式版采用双阈值：绝对上限负责阻断异常膨胀，相对基线涨幅负责防止每次小幅增长累积。若后续 CI 实测超过 1100KiB，不应继续抬线，应先检查文本变化、unicode-range 命中与浏览器字体选择差异。
