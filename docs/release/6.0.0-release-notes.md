## 一、这是什么

ALE 品牌的 WebUI 设计体系 6.0.0:设计令牌单一真源(tokens/*.json 生成链)+ 三档工程骨架(React/Alpine/Static)+ 46 项自动化设计门禁 + 治理机制(例外台账/发布锁定/性能基线/CI 自诊断)。三项目试点(TSSKB/dan-cpl/nvci-lite)已完成 v6 令牌迁移并锁定于 release-lock.json。

## 二、6.0.0 相对 5.4.1 的主要变化

**规范与令牌**
- 版本真源切换 6.0.0;docs/v6 四层治理文档(62 条 must 规则注册表,零漂移门禁);
- 对比度三分类口径(PASS/EXEMPT/SKIP,SKIP=0 硬门槛);暗色 on-action 补值;
- 试点回流条款:向导/两栏 320+768 堆叠、徽章色板、中性底角色化、bridge 迁移模式。

**工程骨架**
- 14A 数据表功能包(排序/键盘列宽/分页/防抖搜索/批量)在 React/Alpine 双骨架;
- 表格 320/768 三档横向滚动口径;表单必选同意契约 + Field ARIA 自动注入;
- AppShell 抽屉焦点圈闭/归还;全入口主题持久化(单一 storage key)。

**字体**
- 自托管 Noto Sans SC(400/700,SIL OFL 1.1);真 unicode-range 分片(首屏 2.3MB→0.5-1MB);
- A/C 双轨定版:A=动态默认;C=按文本子集(可穷举静态页,font:cov 覆盖门禁);对比页 /fonts-compare.html。

**门禁与治理**
- design:check 全套(规范站 + Kit 四入口,含键盘链/768/主题跨入口/reduced-motion/字体预算);
- 性能双门禁(绝对上限 + 基线×1.10 相对限,JS/CSS 分项记录);
- design-exceptions.yml 例外台账(schema v2:not-applicable/exception 分类,里程碑绑定);
- release-lock.json 发布组合锁定;CI 失败自诊断(失败步骤/逐项结果/环境/指标回写仓库);
- pilot:tokens-check(颜色硬门槛 + 非颜色迁移观测指标)。
