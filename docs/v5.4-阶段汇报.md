## 2. 五项 P0 整改与复测

| # | 评审问题 | 根因（实测定位） | 修复 | 复测结果 |
|---|---|---|---|---|
| P0-1 | 版本真源漂移（文档 v5.3 / 页面 v5.1 / README v5.2） | 版本号手工散布多处 | 新增 `design-system.version.json` 单一真源；title/meta/页脚统一 v5.4；**deploy.js 发布门禁强制校验版本，不符拒绝发布** | `document.title = "…v5.4"`，与 version.json 一致 |
| P0-2 | 320px 页面级横向溢出 10px | 双层根因：网格 `minmax(320px,1fr)` 强制最小列 + 紧贴右缘的热区伪元素顶出 topbar padding | 全站网格列 `minmax(min(Npx,100%),1fr)` 钳制；热区分档 + 小屏 padding 收紧 | **scrollWidth 305 = clientWidth 305，零溢出** |
| P0-3 | 42–43 个交互元素热区 <44px；例外口径藏附录 | 可见尺寸与命中热区混为一谈 | 口径统一进正文：触控 ≥44 / 桌面热区 ≥40（可见可 32/36/40）；三档高度令牌；伪元素扩热区 | 排序 **44** / 分页 **44** / 复选框 **44** / 图标按钮桌面 40（触控 44） |

| P0-5 | "两类需求"与"三种形态"分类轴混用 | 家族与技术档位同层 | 0.1 章改二维模型：**2 产品家族 × 交互模式**，向导归入工具应用，附工程档映射 | 已入规范 0.1 章 |

**额外整改**（评审 §6.3 实测发现的字体回退）：定位并消除 Times/Arial 命中（BUTTON 不继承字体 → `font:inherit`；等宽栈补中文回退）。

## 3. 过程中发现的上线回归（自我暴露）

整改上线后用户报告"点导航切换主题/语言"。根因：热区伪元素 `.icon-btn::before` 的控件缺 `position:relative`，伪元素相对 topbar 铺满形成全栏透明热区层。**当日修复并复测**（7 个导航链接 elementFromPoint 全部命中自身）。已回流规范：附录 **F13** + 第 9/11.1 章前置条件铁律 + hit-test 抽查要求。

> 该回归同时印证了评审的核心判断：**没有自动门禁，质量靠人的细心不可持续**——这正是 v6.0 要解决的问题。

按评审同口径八维度自评：**综合 78 → 约 81**（响应式 68→79、无障碍 70→77、信息架构 76→80、治理 72→75，其余持平）。品牌/组件/工程持平——本轮定位是"止血"而非"扩展"。
