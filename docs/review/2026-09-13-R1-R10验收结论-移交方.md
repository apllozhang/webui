## 四、R11(新增,必改):React 骨架 1440px 表格 filler 空白列

**现象**:kit-react 1440px 下,表格最后一列"大小(KB)"之后存在约 30% 宽的空白列区——表头紫带与行分隔线延伸到表格右缘,但无表头文字与数据,观感像未完成的断列(见 `kit/tools/design-check/artifacts/kit-react-1440.png`)。

**根因**:`DataTable.tsx` 初始模式(未拖动)下 `minWidth:100%` 填满容器,余量由 `<th class="filler">` 吸收(F14 双模式机制);但 filler 继承了 `thead th` 的紫色背景与边框样式,视觉上呈现为一条空列。该问题在 R1 修复前因 React 空白页不可见,故首次由 R10 门禁截图暴露。**非回归,存量视觉缺陷。**

**修复方向(实现自定,二选一即可)**:
1. 初始模式列宽改按 `size/totalSize` 百分比拉伸填满,消除余量(filler 宽度归零);
2. 保留 filler 但视觉中性化:`thead th.filler` 背景透明、去排序列样式,`td.filler` 仅保留行底边框,使其读作卡片留白而非断列。

**完成定义(DoD)**:
- 1440px 下 React 表格视觉连续,无"断列"观感(截图入 artifacts);
- 不破坏:F14 列独立性(`verify-colresize` 双目标 PASS)、320px 横向滚动行为、`design:check` 32/32 全绿;
- 提交后推送,移交方复核 1440 截图即关闭 M4。
