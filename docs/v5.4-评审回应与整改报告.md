### P0-2 320px 页面级横向溢出 10px —— ✅ 已修复（复测 0px）

复现定位发现溢出实际有**两层根因**：

1. **10px 主因**：令牌区网格 `repeat(auto-fit, minmax(320px, 1fr))` 在 305px 可视宽下强制最小列 320px。修复：全站所有 ≥260px 的网格列统一钳制为 `minmax(min(Npx, 100%), 1fr)`，并写入规范第 9 章为强制写法；
2. **2px 残留**：紧贴 topbar 右 padding 的汉堡按钮，其 `::before -2px` 触控热区扩展顶出容器（291 内容溢出 + 16 padding = 307）。修复：图标按钮热区按指针类型分档（见 P0-3），小屏 topbar padding 收紧至 12px 容纳扩展。

**复测**：320px 视口 `scrollWidth 305 === clientWidth 305`，根节点零溢出；表格 954px 仍在容器内滚动，首末列可达。验收口径与评审建议一致（`scrollWidth === clientWidth`）。

### P0-3 44px 触控基线矛盾 —— ✅ 已修复（采纳评审口径，正文收编）

- **口径统一进正文第 9 章**（不再藏附录）：触控/粗指针环境热区 ≥44px；桌面精确指针环境可见高度可 32/36/40px（新令牌 `--control-height-compact: 36px` / `--control-height-default: 44px` / `--hit-target-min: 44px`），桌面命中热区 ≥40px；
- **实现**（可见尺寸不变，伪元素扩热区）：表格排序按钮 22px→热区 44px；分页按钮 32px→44px；表格复选框 16px→44px（`appearance:none` 自绘，选中态紫底白勾）；顶栏图标按钮 40px（桌面），`@media (pointer: coarse)` 下扩展至 44px；
- **复测**：排序 44 / 分页 44 / 复选框 44 / 图标按钮 40（桌面口径）。

### P0-4 排版规定与实现不一致 —— ✅ 已修复（采纳"视觉角色 × HTML 语义"两层模型）

- 规范第 4 章新增**五角色表**：Display 44/32、Page title 32/26、Section title 24/21、Subsection title 19/18、Card title 16/16——视觉尺寸归角色，HTML 标签只保证 h1→h2→h3 连续；
- 演示站修复：卡片标题回归 **16px**（原 .98rem）；hero h1 44px 合法化为 Display 角色；task-cards 区补 `sr-only` h2，**消除 h1→h3 跳级**；
- **复测**：标题序列 H1:44(Display) → H2:24 → H3:16…，卡片标题 16px。

## 二、信息架构 —— ✅ 采纳"二维模型"

规范 0.1 章已重构为 **2 产品家族 × 交互模式**：

| 家族 | 交互模式 | 工程档 |
|---|---|---|
| 内容网站型 | 阅读门户 / 检索目录 / 长文详情 | Static |
| 工具应用型 | 工作台 / 数据管理 | React |
| 工具应用型 | 轻量表单 / 单任务 | Alpine |
| 工具应用型 | 多步向导 | React 或 Alpine |

"向导"降为工具应用的一种交互模式，不再与"应用"并列。评审指出的概念混用（"两类需求"vs"三种形态"）已消除。
