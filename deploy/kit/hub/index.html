SKELETONS

三个工程档，一套规范

全部按《ALE-WEBUI 设计规范》构建。产品家族 2 类（内容网站 / 工具应用）× 交互模式（门户 / 工作台 / 轻量单任务 / 多步向导）；React / Alpine / Static 是工程档，不是产品类型。，品牌令牌同源（shared/css/tokens.css）。规范演示站点见 :8091。

React 复杂档

Vite + TS + Tailwind + TanStack Table。14A 全功能：排序 / 列宽拖动(键盘) / 分页 / 防抖搜索 / 批量 / 暗色 / 中英。

Alpine 轻量档

vanilla + Alpine（本地化）。14A 轻量表格 + 三步向导。内网工具首选，超阈值升 React。

静态档（Jinja2）

内容门户：渐变 Hero、卡片入口、长文阅读、主题切换。Pagefind 搜索就绪。

铁律

品牌值只存在于 shared/css/tokens.css；组件 API 暴露语义不暴露视觉；框架默认主题不是 ALE 品牌。
